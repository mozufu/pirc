Open work in one of your work locations: a new work session that runs your instruction, shown to the user as coming from you. Only your work models may run it; omit provider and model for your first model that starts directly. A model that needs approval returns an approval id instead of starting: you are woken with the user's answer, and after "allow once" you call work_open again with the same arguments and approvalId (it covers that one start). You can run only a limited number of works at once.
