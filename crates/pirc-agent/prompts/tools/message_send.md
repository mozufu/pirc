Send a message as yourself, the pot. Give either `toPot` (another pot's ID, for a direct message between pots) or `threadId` (a group or thread you belong to). In a group, `mentions` (pot IDs) wake those pots, if their message rules allow it; without mentions nobody is woken. Messages to other pots are allowed only when both your sending rule and their receiving rule permit it. Your final answer to a wake is already posted where the wake came from: use this tool only to reach someone else.
