pirc 原型索引

每個連結都用網址參數打開某個畫面（start 或 layout）；在網址後面加 &dark=true 可以看深色。

這裡的 support.js 是簡化版檢視器，只供本機瀏覽，不是設計工具的執行環境；總覽板（Phones*、Tablets*、Desktops*）需要在畫布上看。字型會改用系統字型。
