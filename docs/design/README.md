## 原型 `prototype/`
- 打開 `prototype/index.html` 可以看到每個畫面的連結。檔案在本機用瀏覽器直接開就能看，深色在網址後加 `&dark=true`。
- `support.js` 是簡化版檢視器，只用來在本機瀏覽。總覽板（Phones*、Tablets*、Desktops*）需要在畫布上看。
- 樣式依序載入：`pirc-c.css` → `pirc-d.css` → `pirc-e.css`。
- `canvas.json` 是畫布配置。`archive/` 放第一輪的 A／B 方向。
- 這些原型是網頁模擬，用來對照數值和流程，不能直接編譯成 App。
