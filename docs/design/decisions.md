## 1. 現在的方向：E · 聊天式 pots

### 版面
- **分頁**：手機底部分頁列，依序是聊天、工作、動態、行事曆。
  - 聊天：只放 pots 與群組。
  - 工作：session，依專案分組。
  - 動態：pots 做的每件事。
- **側欄**：左上 ☰ 打開。
  - 內容只有主機狀態。
  - 底部依序是「設定」按鈕、亮暗切換、你的頭像與名字（點進去是使用者與用量）。
  - 打開時把頁面推開，不蓋在上面，所以不會有被切一半的圖示（穿模）。
- **工作（session）不放頭像或資料夾圖示**。誰在協調，用文字寫在「From 測試員」或「你」。
- **pots 頭像右下角只有兩種標記**：
  - 綠色三點膠囊（高 16）＝工作中。
  - 灰點＝無法工作，包括暫停、額度用完、主機或模型都不能用。
  - 可以工作時不標；封存的 pots 不出現在列表。
- **對話樣式**：pots 對話用泡泡加頭像；工作沿用 D 的文件式對話。
- **決定卡**：標題前不放圖示。

### pots（好友）與群組
- **新增 pots 共四步，建立時就把所有設定配好**：
  1. 外觀與個性：頭像、名字、soul。
  2. 工作內容：簡介、工作說明、負責的事。
  3. 能做什麼：
     - 能做到哪裡：只回答／觀察並建議／可以開始工作。
     - 能看什麼。
     - 私訊其他 pots：傳送與接收分開設，各自可選所有／選擇的／關閉，預設開啟。
     - 開工位置、額度、同時進行的工作數。
  4. 模型：
     - 主模型加上依序的備援。
     - 思考程度，以及「依情況自己調整」。
     - 開工作時可以用的供應商／模型，每個模型設成「直接用」或「先問你」。
- **個性與工作說明不給任何權限**。
- **依情況自己調整思考程度**：平常用設定的程度，需要時自己調高或調低，**不會問你**；每次調整都記在動態並寫出原因。
- **pots 要用更強的模型，就是開一個工作、選好模型、跟它對話**。只能選被允許的模型。
- **「先問你」的模型，核准畫面只有三個選項**：拒絕、拒絕並說明原因、允許這一次。
- **額度一律用金額或 token 計算**，不用「幾個工作」。同時進行的工作數是另一個上限。
- **群組**：
  - 建立與設定時都能改名稱和頭像，頭像預設用成員頭像。
  - 沒有 @ 任何人時由**主持**回覆並分工；@ 誰就由誰回。
  - **權限不因為在同一個群組而合併**；主持把事交給別人時，對方只用自己的權限。

### 交接、暫停、封存、刪除
- **pots 之間隨時可以交接**，不必移除。pots 自己提出的交接要你確認。
- **交接只轉移事情，不轉移權限**。接手者權限不夠時會標出來，範圍會縮小，不會自動加權限。
- **暫停只是提示**：列出哪些暫停、哪些照常，不移交任何東西。
- **封存（可恢復）或刪除（刪除個性、記憶、設定）**：
  - 先逐項決定負責的事、追蹤、它協調的工作、群組主持要交給誰。
  - 再列出會失效的與會保留的。
  - 執行順序是先交接、再撤銷權限。

### 透明度
- **動態**：記錄 pots 之間的私訊、交辦、送進工作的指示、讀取的檔案、思考程度調整、備援切換、提議交接。**沒有你看不到的頻道**。
- **pots 的視角**：唯讀模擬它看到的聊天列表與對話紀錄，右邊是它送出的訊息，包含送進工作的指示；不能用它的身分發訊息。

### 設定與使用者
- **設定頁**：
  - 帳號
  - AI：pots、模型供應商、你的預設模型、記憶
  - 通知與權限
  - 一般：語言、外觀、文字大小、時區、打開 App 時、觸覺回饋
  - 資料
  - 關於
- **設定 → pots**：
  - 最上面是全部 pots 的合計上限（每月金額、每天 token）、用完時怎麼處理、動態保存天數。
  - 下面列出所有 pots，點一位打開它的完整設定，內容和建立時的四步相同。
  - **沒有全域的 pots 設定頁**。
- **使用者與用量**：
  - 總覽數字。
  - token 活動：每日熱度圖、每週、累計。
  - 本月誰用了多少、用了哪些模型。
  - 可以改名字與頭像；分享時只產生圖表圖片。

## 2. D · 統一對話（架構調整）留下來的決定

E 沿用以下內容，畫面在 `screenshots/D-*`：

- 沒有聊天／工作之分；一個對話可以有多個任務，任務列放在頂部。輸入框可以選訊息要傳給誰。
- **工作區**：主機、主要資料夾、掛載。切換或移除掛載時：
  1. 先預覽，再套用。
  2. 撤銷舊權限完成前，不在新位置開工。
  3. 失敗也不恢復舊權限。
- **離開、刪除專案**：預覽分開列出會中斷、會刪除（擁有的）、保留（只是引用）、仍有的獨立權限。
- **檔案**：已保存的附件和即時檔案參照分開；後者每次都要檢查目前權限。
- **行事曆**：
  - Agent 任務的執行目標是「專案＋工作區」；目標被移除時暫停並要你重選，不會自動換地方。
  - 錯過的執行要你允許才補跑。
- **通知分級**：立即／摘要／不通知。
- **「From pots」標示一律由後端給予**，不能用文字冒充。

## 3. C · 網頁風格留下來的決定

E 沿用以下內容，畫面在 `screenshots/C-*`：

- 視覺：
  - 沿用網頁的圓角、陰影、系統字體、Lucide 線條圖示。
  - 主色改成較沉的 #4B6BA6；送出鍵用墨色，藍色只給選取、連結、執行中。
  - 每個表面只用一種區隔方式：浮起的用陰影、成組的用底色、細線只給表格與列表分隔。
  - 深色模式靠明度差區分層次。
- 模型與思考程度：輸入框只留一個入口，打開後是設定式兩列。
- **Android 大型互動通知**：
  - 選項直接放在通知上，最多 3 個。
  - 點了先開 App、重新取得狀態，確認仍有效後才顯示預選答案，**不會直接送出**。
  - 其他狀態：已被其他裝置處理、已過期、鎖定畫面只顯示標題。
- **下方快速回應視窗**：顯示在其他 App 上層，狀態確認前按鈕不能按。
- 工作面板（檔案、Git、終端、Tasks、記憶、瀏覽器）與全螢幕終端，沿用 Android 現有的終端列表。
- 狀態一律用文字加符號，不只靠顏色；失聯後不宣稱成功、不自動重送。

## 4. 還沒決定的事
- 封存的 pots 恢復後，交接出去的事要不要問你是否拿回。設計稿目前不自動拿回。
- 群組和專案的關係：目前分開，群組可以綁專案。
- 摘要時間、勿擾預設、App 登入方式（D 遺留）。

以下原本列在這裡，已在 pirc 2 決定（`plans/README.md`，2026-11-24）：
- 交接時，給原 pots 的同意會轉給接手者，開始前重新檢查權限（P8）。
- pots 之間可以不經主持直接交辦，條件是傳送方有交辦權、接收方有執行權（P8）。
- 每位 pots 的記憶互相隔離（P8）。
- @所有人保留，只有使用者能用，送出前提醒會叫醒每位 pots（P9）。
- 成果更新由使用者切換，不自動切換（C 的 3A，P1）。

## 5. 需要後端支援（E 新增；C、D 的需求見各自規格）
1. 多個 pots 身分，每位各自有個性、記憶、負責的事、授權、額度與暫停狀態。目前 `plans/pots/design.md` 第一階段只有一個 pots 身分。
2. 群組：成員、主持、名稱與頭像、綁定專案，以及訊息路由（主持、@ 某位、所有人）。
3. pots 之間的私訊與交辦都要成為有紀錄的事件，使用者全部可讀；每位 pots 有自己的私訊傳送與接收規則。
4. 動態紀錄與「視角」查詢，可依 pots 篩選與分頁，保存天數可以設定。
5. 交接、封存、刪除：
   - 有版本的移轉。
   - 接手時重新檢查權限。
   - 先交接，再撤銷權限。
6. 模型相關設定：主模型與備援順序、思考程度與自動調整、開工作可用的模型與「先問你」規則、一次性的核准事件。
7. 額度以金額或 token 計算，包含每位 pots 與合計；同時進行的工作數另外計算。
8. 用量統計：每日 token、費用、連續使用天數、依來源與依模型的分布。
