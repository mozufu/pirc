# pirc 設計規格 · 方向 E（聊天式 pots）

2026-11-23 · 這份規格以 C（視覺、元件）和 D（統一對話架構）為基礎，只寫 E 新增或改動的部分。重點決定見 `decisions.md`。

原型檔：
- `prototype/PhoneE.dc.html`：手機
- `TabletE`：平板橫向
- `TabletPE`：平板直向
- `DesktopE`：電腦

樣式在 `pirc-c.css` → `pirc-d.css` → `pirc-e.css`，依這個順序載入。截圖在 `screenshots/E-*`。

---

## 1. 資訊架構

```
底部分頁（手機）／左側分頁列（平板、電腦）
├─ 聊天：pots 與群組
│   ├─ pots 對話 → pots 資料 → pots 設定
│   └─ 群組對話 → 群組資訊
├─ 工作：session，依專案分組（全部／需要你／執行中／我開的／pots 開的）
│   └─ 工作（沿用 D 的對話：任務列、From、接管）
├─ 動態：pots 做的每件事（可依 pots 篩選）
│   └─ pots 的視角（唯讀）→ 視角中的一段對話
└─ 行事曆（沿用 D）

側欄（☰）：主機狀態｜設定｜亮暗切換｜你（使用者與用量）
設定：帳號、AI（pots、模型供應商、預設模型、記憶）、通知與權限、一般、資料、關於
```

「需要你」的事放在兩個地方，不另外做一個收件匣：
- pots 的決定：留在該 pots 的對話裡，列表上顯示「待你」。
- 工作的問題、核准、驗收：放在工作分頁的「需要你」篩選。

分頁上的數字徽章一律用黃色。

## 3. 列表

- **pots 列**（`e-row`）：
  - 頭像 48，名字 16／500，角色 12.5 muted，時間；第二行是預覽 14。
  - 數字徽章：一般未讀用墨色；「待你」用 `status.warningSoft`。
- **群組列**：兩個成員頭像疊放（`e-avg`）。
- **工作列**（`e-row.noav`）：
  - **沒有頭像**，文字從 16 的邊距開始，高度 64。
  - 第一行是標題加「From 測試員／你」。
  - 第二行是主機加狀態（◐ 執行中、◆ 等你回答、✓ 待你驗收、◷ 排隊）。
- **專案分組頭**（`e-projh`）：資料夾圖示、專案名、數量。
- **頭像狀態**（`e-av .st`）：
  - 工作中：綠色三點膠囊，高 16，點會輕輕閃動；系統設定減少動態效果時不閃。
  - 無法工作：灰點。
  - 可工作：不標。
  - 標記外圈一律有 2.5px 頁面底色的框。

## 4. pots 的建立與設定

| 步驟 | 內容 | 規則 |
|---|---|---|
| ① 外觀與個性 | 頭像（5 色＋上傳）、名字、個性（範本：嚴謹／簡潔／友善／自訂）、說話預覽 | 個性不給權限 |
| ② 工作內容 | 簡介（列表與 @ 選單會顯示）、工作說明、負責的事 | 工作說明不給權限 |
| ③ 能做什麼 | 能做到哪裡（三選一）；能看什麼（逐項開關）；私訊其他 pots（傳送、接收各自三選一，選「選擇的」時可勾選 pots）；開工位置；額度（金額或 token）；同時進行的工作數 | 只有選「可以開始工作」才出現開工區 |
| ④ 模型 | 主模型；備援 1、2…；思考程度（低／中／高／最高）；依情況自己調整；開工作時可以用的模型（逐一勾選，各自設「直接用／先問你」） | 不能開工作時，用說明取代模型清單 |

- **pots 設定頁**（`potsEdit`）和建立時的四步內容相同，最下面多了暫停、交接、封存或刪除。進入方式：pots 資料右上的「設定」，或「設定 → pots → 點一位」。
- **設定 → pots**（`potsList`）：
  - 最上面是全部 pots 的合計：本月金額、今天 token。
  - 接著是合計上限、用完時怎麼處理、動態保存天數。
  - 下面是 pots 列表與已封存的 pots。

## 5. 模型核准

只有設成「先問你」的模型才會跳出核准畫面。

- **底部彈出面板內容**：工作名稱、模型與思考程度、為什麼要用、預估費用與剩餘額度。
- **三個按鈕**：拒絕、拒絕並說明原因、允許這一次。
  - 「拒絕並說明原因」會展開輸入框，送出後原因會出現在和該 pots 的對話裡。
  - 「允許這一次」只對這一次有效。
- 待核准的工作會同時出現在「工作 → 需要你」和動態（標示「等你核准」）。

## 6. 交接、暫停、封存、刪除

- **交接**（`handover`）：
  - 先選接手者，再勾選要交接的事。
  - 每一項顯示接手者的權限是否足夠：✓ 足夠／! 範圍會縮小／■ 會停止。
  - pots 自己提議的交接，上方會有說明橫幅。
- **封存或刪除**（`retire`）：
  - 用分段控制選封存或刪除。
  - 「可以交接」逐項選交給誰：其他 pots、你，或不交接。也可以用「全部交給…」一次設定。
  - 點一項展開，會顯示需要什麼權限、會做什麼，以及「調整○○的權限…」。
  - 下面是「會移除或失效」與「保留」兩區。
  - 按鈕依選擇顯示「交接並封存」或「交接並刪除」。
- **暫停**：底部彈出面板，分「暫停期間」和「照常」兩區，不移交任何東西。

## 7. 動態與視角

- **動態列**（`e-log`）由這些部分組成：
  - 頭像、「誰 → 對象」、時間。
  - 類型標籤：私訊、交辦、送出指示、讀取、自動調整、備援、等你確認、等你核准、轉給你。
  - 內容摘要，最多兩行。
- 只看某一位 pots 時，上方會出現「查看○○的視角」。
- **視角**（`pov`、`povChat`）：
  - 上方固定說明「唯讀・模擬它看到的」。
  - 右邊泡泡是它送出的訊息，底色是它頭像色的 18%；左邊是對方，工作用資料夾小圖。
  - 底部是唯讀列，加上「前往工作／回到動態」。

## 8. 使用者與用量

- **總覽**：6 個數字（`e-stats`），手機排 2 欄、平板與電腦排 3 欄。
- **Token 活動**：
  - 每日熱度圖：同一個主色、5 階，手機 18 週、平板 26–30 週、電腦 40 週，每格有提示。
  - 每週：12 週長條，本週用實色。
  - 累計：面積折線。
- **本月誰用了多少、用了哪些模型**：用長條列表（頭像或縮寫、名稱、長條、數值）。不用分類色，因為頭像色太接近，色盲和一般視力都難分辨。
- **編輯個人資料**：底部彈出面板，可以換頭像（顏色或上傳）和改名字。pots 會用這個名字稱呼你。
